# Inviting people

## Invite by link
A workspace admin or the account owner creates an invitation link for one email address. The link works only for that address, so the person must be signed in with the same email to accept it.

## How long it lasts
An invitation is valid for 7 days and can be used once. An admin can resend it or revoke it before it is accepted.

## Projects on the first day
When inviting, the admin picks the projects the person joins on the first day.

## Roles and removal
An invited person joins as a workspace Admin or Member. Only admins and the owner can change roles or remove members. Project admins add existing workspace members to their project but cannot invite new people to the workspace.
