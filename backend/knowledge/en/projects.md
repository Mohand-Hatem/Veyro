# Projects

## Private by default
A project is a private board. Only the people added to it can see it. Workspace admins and the account owner can see all projects of their workspace.

## Who creates and manages projects
Workspace admins and the account owner create, archive, delete and restore projects. A project admin manages the members and tasks of their own project and can rename it and edit its description.

## Archived projects
Archiving makes a project read-only: tasks cannot be created, changed or moved, but everything stays readable. An admin can unarchive it later. Archived projects count toward the plan limit.

## Deleted projects
A deleted project is hidden and does not count toward the plan limit. An admin can restore it if the plan still has room for one more project.

## Read-only because of the plan
A project can also be read-only because the plan is at its limit, for example after a downgrade. That is different from archiving. The account owner chooses which projects stay editable.

## My tasks
The My tasks page lists everything assigned to you across your projects, ordered by due date.
